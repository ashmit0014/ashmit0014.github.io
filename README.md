# ashmit0014.github.io

Source of [ashmit0014.github.io](https://ashmit0014.github.io). One page, plain HTML and CSS, a small script for two behaviours (the tint that follows the section in view, and the Sidekick screen switcher), no build step, no tracking.

- Type: Newsreader and Hanken Grotesk, self-hosted (SIL OFL); Bellhollow's title uses the game's own font, Silkscreen (SIL OFL).
- Images: real screenshots from [Sidekick](https://github.com/ashmit0014/sidekick-ipad) and [Bellhollow](https://github.com/ashmit0014/bellhollow-game); the flood masks are from [sar-flood-detection](https://github.com/ashmit0014/sar-flood-detection), recoloured for the page.
